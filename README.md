# IoT Water Quality Monitoring System

## Project Overview
This project focuses on developing an IoT-based water quality monitoring system. It uses sensors and a microcontroller to measure water quality parameters and display the collected readings.

## Objectives
- Monitor water quality using sensors.
- Interface sensors with a microcontroller.
- Acquire and process sensor data.
- Display the measured output.

## Hardware Components
- Microcontroller:Esp32
- Sensors: tds sensor
- Display: lcd
- Connecting wires and power supply

## Software and Tools
- Embedded C / Arduino IDE
- thingsspeak
- blynkiot
